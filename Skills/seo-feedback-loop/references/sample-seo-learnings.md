# SEO Learnings — Template

> This is a sample file showing the correct format for extracted learnings.
> Copy this format when creating your own `seo-learnings.md` file.

- **Discovered:** [Date]
- **What changed:** [Specific before → after description]
- **Evidence:** [What improved and how we know]
- **Principle:** [The reusable learning extracted]
- **Pages affected:** [List of URLs or page types]
- **Learning extracted:** [Reference to learning in seo-learnings.md]
- **Propagation:** [X pages identified] — see propagation plan below

## Example Entry

```markdown
- **Discovered:** 2024-01-15
- **What changed:** Rewrote homepage title from generic brand-first ("Example Inc | Software") to keyword-first with deliverable ("Custom Software Development for SMBs | Example Inc"). 
- **Evidence:** CTR improved from 1.2% to 2.1% over 4 weeks. Ranking for "custom software development" improved from #15 to #8.
- **Principle:** For service pages, including a specific deliverable qualifier (what you build, not just who you are) in the title tag improves rankings and CTR. Google interprets this as higher relevance to commercial-intent queries.
- **Pages affected:** [/software-development, /app-development]
- **Learning extracted:** See learning entry #[N]
- **Propagation:** [2 pages identified] — /enterprise-software and /mobile-app-development should follow the same pattern
```

## Key Characteristics of Good Learnings

1. **Principle-level, not tactic-level** — Explain the why, not just the what
2. **Specific evidence** — Include the metric improvement when possible
3. **Reusable across pages** — The principle should apply to other similar situations
4. **Clear propagation path** — Note which other pages should follow the pattern
