# Keyword Registry

Track primary keyword ownership per page. Update this file when a
`blog_write` or `rewrite_blog_content` task changes a page's target.

Rules:

- One primary keyword per page.
- Before writing a new post, check for the same or a very close keyword.
- Treat the same root intent, audience, and SERP as a conflict.
- If there is a conflict, stop and recommend a different angle or a merge/redirect.
