# SEO Task Backlog

_This file is generated by the SEO Audit skill and updated as tasks are created in the Kanban board._

## How to populate this file

Run an SEO audit via the Kanban UI or CLI:

```bash
python main.py "Perform an SEO audit on https://yoursite.com"
```

The agent will populate this file with prioritised tasks grouped by severity.
